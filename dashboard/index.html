How the value model works

Every implied value follows from the snapshot's own figures. No protocol name is ever special-cased: the same function scores every row.

implied = TVL × 0.30 × growth × maturity × chains × category

Growth

Seven-day TVL change, clamped to −50%…+150% (unreported counts as 0):
growth = 1 + change × 0.006

Maturity

Days since DefiLlama began tracking it, up to 1,460 days (unknown counts as 365):
maturity = 0.70 + 0.30 × age ÷ 1460

Reach

One chain counts as 1.00; each extra chain adds 0.02, up to 1.10:
chains = 1 + 0.02 × min(chains − 1, 5)

What the board leaves out

A protocol is ranked only when it records no token and is not a bridge, a liquid-staking or restaking product, a CEX, a versioned pool, a wrapped or staked product, or a protocol whose name begins with an exchange's name. Protocols above the floor that the watchlist leaves out are not ranked: the house's rule screened them out, and this board does not second-guess it.

“Records no token” is DefiLlama's record, not proof a protocol has none. The implied value is this radar's own claim about what a launch would be worth if the protocol's record stayed as it is — never a prediction that a token is issued, or when.
